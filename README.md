# ResQ

**ResQ** is a Zero-Hallucination Safety & Reliability Guardian built with Flutter. It provides pre-change risk prediction, instant rollback checkpoints, digital fraud detection, and an intelligent AI Safety Assistant.

## Features

- **Software Safety Guardian**:
  - Pre-change risk evaluation with AI confidence metrics
  - One-click snapshot recovery point creation & rollback
  - Controlled environment failure simulation and automated AI diagnostic triage
  - Unprotected execution path with continuous telemetry monitoring

- **Digital Fraud Safety Hub**:
  - **Message**: Urgent phishing & suspicious text detection
  - **Link**: Typosquatting, unencrypted HTTP, and malicious URL scanner
  - **Bank Msg**: Financial scam and urgent KYC deactivation alert detection
  - **QR / Pay**: Merchant display name vs registered payment recipient verification

- **ResQ AI Assistant**:
  - Live device and telemetry data analysis
  - 12 interactive Frequently Asked Questions
  - Multilingual support including English, Hindi, and Hinglish
  - Integrated Voice Assistant modal

- **Device Catalog**:
  - Dynamic Brand → Model selector across 10 top smartphone brands

## Getting Started

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (3.13+ recommended)
- Google Chrome or desktop runner

### Run Locally

```bash
# Get dependencies
flutter pub get

# Run on Chrome
flutter run -d chrome --web-port=5000

# Run on Windows Desktop
flutter run -d windows
```

### Running Tests

```bash
flutter test
```
